### Step 1 · DumpApi → picogk_api.json
- Change: `tools/DumpApi` now references the `PicoGK` 2.2.* package directly and reflects
  `typeof(PicoGK.Voxels).Assembly` explicitly (old code walked `AppDomain.GetAssemblies()`, which never
  contains PicoGK because nothing touched a PicoGK type → would have emitted 0 types — BUG fixed).
  Adds ctors, `in/out/ref/params`, default values, nested types, enums, operators. Output is
  deterministic (no timestamp) so `symbolTableHash` changes only when the API changes.
- DECISION: DumpApi no longer has a ProjectReference to ForgeSandbox. Kit is reflected from an optional
  second argument (`dump-api out.json path/to/forge-sandbox.dll`). Reason: the API truth must be
  producible before the sandbox compiles (it is what the sandbox is fixed against).
