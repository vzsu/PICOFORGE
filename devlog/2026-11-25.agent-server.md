   **TOOL-EXPORT-01..03** — `export_artifact` → engine writes `<dataDir>/runs/<runId>/exports/<name>`;

## DECISION / SPEC-GAP

- SPEC-GAP: docs/04 §5 names `engine.build {codeId, params, …}`; the engine host (`Program.cs`) and
  `client.ts` use `engine.run`. Kept `engine.run` (renaming would break the host). Engine lead should pick one.
- SPEC-GAP: no export RPC in 04 §5. DECISION: `EngineClient.export` calls the host's existing
  `engine.convert` stub with `{target, format, outPath}` → `{path, bytes}`. Engine agent must implement it.
- SPEC-GAP: `engine.inspect` reply shape unspecified. DECISION: `{target, measurements{volumeCm3, areaCm2,
  bboxMin, bboxMax, triangles, watertight, minWallMm}, results[{type,…}]}` (`engineInspectResultSchema`).
  The host stub currently returns `{ok, note}` → would surface as ENGINE_PROTOCOL (F15).
- DECISION: brief parameters only carry numeric `value` (no `expr` yet, `domain/expr.ts` does not exist),
  so "evaluated" = `value`. Switch to `evalParams` when 08 §3 expressions land.
- DECISION: run_picogk without an accepted brief still builds with `params: {}` and skips the envelope check
  (MCP-02 `BRIEF_REQUIRED` not enforced here — not in the failure table yet).
- DECISION: min wall includes 3 × voxel (PICOGK_KNOWLEDGE "Print minimums"); tool-level triangle cap 10M.
- DECISION: `search_docs` without a DB returns archive-doc hits instead of a stub/error.
- New FAIL drills needed for F15/F16 (11 §3 `FAIL-F1..F14` → extend to F16).
- Not done: remaining `as` casts outside the touched flow (`anthropic.ts`, `prompts/context.ts`,
  `askUser.ts`, `captureViewport.ts`, `submitDesignBrief.ts` ctx.db, `db/repo/*`).
