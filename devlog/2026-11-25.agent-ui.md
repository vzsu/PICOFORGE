## Iterations (what the screenshots showed)
1. Part too close and cropped; grid far too bright → grid opacity was being mixed in linear space
   (6 % linear ≈ 28 % sRGB). Now mixed in sRGB then linearised.
2. Wobbly rims on bosses → tried a Newton snap onto the exact SDF: it serrated sharp edges and
   flipped triangles. Final: real fillets in the SDF (polynomial smin/smooth-subtract, k 3–7 mm) so
   the 1.5 mm voxel mesh resolves every edge, no projection, exact-SDF normals.
3. Dark specks along boss fillets were backface-culled quads: the per-quad geometric winding test
   failed on skewed quads. Replaced with the static surface-nets winding (x/z +axis, y −axis).
4. Bosses tangent to the side faces made slivers; moved inboard 2.5 mm.

## Surprising
- Playwright's default headless shell renders WebGL with SwiftShader on this machine (renderer string
  `SwiftShader Device (Subzero)`), so "default" perf numbers are software numbers. Use `PF_GPU=1`.
- The first cold run failed once with viewport mode `error`: Vite's first-load dependency
  re-optimisation reload killed the bake worker. Fixed with `optimizeDeps.include`; not seen since.
- `R8` `DataTexture` rows need `unpackAlignment = 1` (contact-shadow width is not a multiple of 4).
